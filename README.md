# NoteCraft (노트크래프트) 🚀

> **노션 스타일의 구조화된 블록 메모**와 **굿노트 스타일의 자유로운 손글씨/필기 캔버스**를 결합한 올인원 반응형 웹 메모 어플리케이션입니다.

🌐 **온라인 데모 / 접속 주소**: [https://kaydenjeje.github.io/notecraft/](https://kaydenjeje.github.io/notecraft/)

---

## ✨ 주요 기능

- **📝 노션 스타일 블록 에디터**:
  - `/` 슬래시 명령어로 대제목(H1), 중제목(H2), 소제목(H3), 체크리스트(To-Do), 글머리 기호, 번호 목록, 인용문, 콜아웃 상자, 구분선 추가
  - 텍스트 선택 시 플로팅 서식 툴바 (굵게, 기울임, 밑줄, 취소선, 3색 형광펜)
  - 스마트 키보드 인터랙션 (`Enter`, `Backspace`, 방향키 이동)

- **✍️ 굿노트 스타일 펜 필기 캔버스**:
  - 만년필/볼펜, 반투명 형광펜, 지우개 도구
  - 6가지 컬러 팔레트 + 커스텀 컬러 피커, 3단계 펜 굵기 조절
  - 디지털 속지 템플릿: 가로줄 노트(Lines), 모눈종이(Grid), 도트 그리드(Dots), 무지(Blank)
  - 태블릿 터치 및 스타일러스 펜 압력 감지(`pressure`) 지원

- **🧭 3가지 뷰 모드**:
  - **통합 모드**: 텍스트 작성과 손글씨 드로잉을 한 페이지에 동시 사용
  - **노션 모드**: 타이핑에 온전히 집중하는 문서 작성 모드
  - **굿노트 모드**: 화면 전체를 실제 종이 노트처럼 펜 필기 전용으로 사용

- **📱 모바일 / 태블릿 최적화 (PWA)**:
  - 브라우저 메뉴에서 "홈 화면에 추가" 시 앱 아이콘 생성 및 주소창 없는 전체화면 앱으로 실행
  - 스마트폰 카메라로 QR 코드를 비추면 즉시 열리는 모바일 QR 연동 지원

#### 3단계: 진짜 앱처럼 설치하기 (PWA 홈 화면 추가)
- **아이폰 / 아이패드 (Safari)**: 하단의 **[공유 버튼]**(네모 위로 화살표) ➡️ **[홈 화면에 추가]** 클릭
- **갤럭시 / 안드로이드 (Chrome)**: 우측 상단 **[메뉴]**(점 3개) ➡️ **[앱 설치]** 또는 **[홈 화면에 추가]** 클릭
- 이제 스마트폰 바탕화면에 NoteCraft 아이콘이 생성되며, 누르면 브라우저 주소창 없이 **진짜 네이티브 앱처럼 전체화면**으로 실행됩니다!

## 4. Google 계정 로그인 및 기기 간 실시간 동기화 연동 방법

이제 NoteCraft는 **Google 계정 로그인**과 **계정별 전용 데이터베이스 격리**를 완벽하게 지원합니다.
로그인하면 오직 **내 구글 계정으로 작성한 메모만 보이며**, 스마트폰과 PC 간에 실시간으로 동기화됩니다!

### 📌 1분 만에 Firebase 무료 연동하는 방법
1. [Firebase 콘솔(https://console.firebase.google.com/)](https://console.firebase.google.com/)에 구글 계정으로 로그인 후 **[프로젝트 만들기]** 클릭 (프로젝트명: `notecraft-notes` 등 자유롭게)
2. 대시보드 화면 중앙의 **웹 앱 아이콘 (</>)** 을 클릭하여 앱 닉네임 입력 후 등록
3. 화면에 나타나는 `firebaseConfig = { ... }` 코드를 복사
4. [NoteCraft 웹사이트](https://kaydenjeje.github.io/notecraft/) 우측 상단의 **[구름 아이콘 ☁️]** 버튼 클릭
5. 복사한 코드를 그대로 붙여넣고 **[설정 저장 및 연결]** 클릭!
6. (최초 1회 설정):
   - Firebase 콘솔 좌측 **[빌드] ➡️ [Authentication] ➡️ [Google] 로그인 사용 설정**
   - Firebase 콘솔 좌측 **[빌드] ➡️ [Firestore Database] ➡️ [데이터베이스 만들기]** (테스트 모드 시작)
7. 이제 우측 상단의 **[Google 로그인]** 버튼을 누르면 언제 어디서나 본인 계정의 메모만 실시간으로 안전하게 동기화됩니다!

- **💾 로컬 영구 저장 및 백업**:
  - 실시간 브라우저 자동 저장 (새로고침해도 보존)
  - 실시간 검색 (`Ctrl+K`) 및 즐겨찾기 고정
  - JSON 파일로 백업 내보내기 및 복원
  - 다크 모드 / 라이트 모드 테마 전환
  - 인쇄 및 PDF 저장 최적화
