Firebase 클라우드 실시간 동기화 설정

구글 Firebase 프로젝트의 웹 앱 설정 코드(firebaseConfig)를 아래에 붙여넣으시면, Google 로그인 및 계정별 실시간 클라우드 동기화가 즉시 활성화됩니다!

상태: 로컬 저장소 모드 (Firebase 미설정)
📌 1분 만에 Firebase 무료 키 발급받는 방법:
  1. Firebase 콘솔 (링크)에 접속하여 [프로젝트 추가] 클릭
  2. 프로젝트 생성 후 웹 앱 아이콘 (</>) 클릭하여 앱 등록
  3. 화면에 나오는 firebaseConfig = { ... } 코드를 복사하여 위 입력창에 붙여넣기
  4. 좌측 메뉴에서 [Authentication] ➡️ [로그인 방법] ➡️ [Google] 사용 설정
  5. 좌측 메뉴에서 [Firestore Database] ➡️ [데이터베이스 만들기] (테스트 모드로 시작)
